One API in front of every model

ModelMux takes the OpenAI chat API and routes each request down a chain of providers. If one is rate-limited, slow or down, the next one answers, before your first token. Send a prompt and watch the route. Source on GitHub.

Answers stream token by token. Anonymous use is limited per visitor.
